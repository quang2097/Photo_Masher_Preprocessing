# Photo_Masher_Preprocessing
This tool is for artificially zooming out a picture using opencv by mashing multiple photos together.

# Update October 27th 2026
Due to recent development this repo is no longer used exclusively for "artificially zooming out a picture using opencv by mashing multiple photos together". But it is now a full blown library for every kind of preprocessing with a useable UI for ease of use for the purpose of handling image datasets such as YOLO26, YOLOv8, COCO Json, etc. The 1.0 version is now scrapped in favor of developing a version 1.0 with a useable interface using imgui or Guilite. The plans are now to add a UI and finish version 1.0 and continue with a second major feature I have in mind which is to make an auto detection tool for labeling images with the help of AI models. Of course the model of use will be public for all to use/distribute in the near future. I intend to have version 1.0 finished by the end of the first week into November.
